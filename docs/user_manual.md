# 智眼识磁 V1.0 用户操作说明书

## 1. 启动 Web 分析

安装根目录 `requirements.txt` 后，运行 `python -m streamlit run app.py`。选择固定相机与示波器位置拍摄的照片，优先点击“已训练 U-Net 自动标定（推荐）”。页面会显示轨迹掩膜、横纵网格测量和关键点；B-H 图优先来自完整分割回线的上下分支中心线。若网格不完整，系统拒绝自动输出；若分割与实际荧光轨迹不一致，可使用人工复核或传统视觉回退。

白色点表示原点/标尺，红色点表示 Hc 交点，蓝色点表示 Br 交点，紫色点表示可见的正负饱和端点。它们是图像坐标或格数测量结果，不能在缺少物理标定时被误写成绝对磁学单位。

界面中的“模型裁剪坐标 px/div”和“显示坐标 px/div”属于不同图像尺寸，数值可以不同；实际物理换算使用显示坐标中的独立 X/Y 格距。八个核心点直接从最终上下分支中心线测量，因此结果图中的特征点与完整曲线共用同一数据源；只有完整分支不可用时才用核心点拟合回退。B-H 结果图和无量纲图均使用响应式 1:1 绘图区，在桌面端居中、在手机端随可用宽度等比例缩放。

回线面积由最终绘制的上下分支在共同 H 范围内积分得到，其数值等于闭合回线的 $|\oint H\,\mathrm{d}B|$。完成真实电路参数标定后，界面将其报告为单周期、单位体积磁滞损耗，单位为 `J/m³`；未完成标定时只能报告 X/Y 通道电压坐标面积 `V²`。无量纲页同时给出归一化面积。饱和端只在上下分支的合并区进行局部约束平滑，中间矫顽区与剩磁区仍保留 U-Net 实测形状。

## 2. 自动采集

启动 `desktop_capture/main.py`，连接 JDY-34 串口，使用 PING/状态读取确认通信。连接开启 USB 调试的 Android 手机，检测设备后导入参数表，设置输出目录与稳定时间，开始自动拍照。任务会记录 manifest，意外中止后使用相同目录再次开始即可识别已完成样本。

## 3. 固件部署

Keil 打开 `firmware/Projects/MDK-ARM/atk_f407.uvprojx` 编译下载，或经核验后使用 `release/firmware/hysteresis_v1.hex`。确认 DAC 通道和示波器 X/Y 接线与项目约定一致。

## 4. AI 训练

准备本地原图、LabelMe JSON 和 metadata 后，按 `ai_pipeline/README.md` 的顺序转换数据、训练 TensorFlow U-Net、批量预测与评估。训练输出应保存为新的版本和运行记录；不得覆盖 V1.0 已训练模型。

## 5. 故障处理

设备缺失、串口授权或 ADB 授权错误应按界面提示处理。自动化任务出现失败时保留 manifest 和日志，先检查供电、蓝牙、USB 授权和固件协议，不要删除已采集图像后重新开始。
