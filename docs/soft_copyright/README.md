# 软件著作权材料准备说明

推荐软件名称：**《智眼识磁——磁滞回线智能视觉分析系统 V1.0》**；简称：**智眼识磁**；版本：**V1.0.0**。

本目录只整理登记准备材料的范围和顺序，不自动生成最终 60 页 PDF，也不替代著作权登记机构的当期表单要求。提交前应由三名共同著作权人确认软件名称、完成日期、首次发表情况、作者署名顺序、申请人和权属证明。

建议提交原创源程序的前/后连续页或全部页（以办理平台现行要求为准），并准备用户操作说明书。不要把 ST HAL/CMSIS、Keil 自动生成文件、Python 第三方库、模型二进制、图片、CSV 数据或构建输出作为原创源码主体。

详见 [source_code_selection.md](source_code_selection.md)。
