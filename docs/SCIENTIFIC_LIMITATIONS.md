# 科学边界与结果解释

## 图像能可靠提供什么

在固定相机、固定示波器布局以及网格可见的前提下，U-Net 可将发光回线从背景中分割，并通过当前照片中的网格/零轴估计轨迹的像素和格数坐标。Hc、Br、饱和端点是由已分割轨迹与零轴/可见极值的几何关系得到的测量候选，仍需要人工复核。

## 图像不能单独提供什么

- 单帧静态图不包含时间信息，不能推出 `LOOP_HZ`。
- 缺少线圈、电阻、电容、磁路、截面积、示波器真实倍率等外部标定，不能从格数伪造 A/m、T 等绝对量。
- 固件将部分输入参数归一化到显示轨迹；静态形状不保证唯一对应 `HMAX`、`BS` 等控制/物理参数。
- 超出屏幕、饱和、遮挡、严重反光或不闭合的轨迹会降低几何点位可信度。

## 数据使用规则

`parameters.csv` 是采集时下发的真值/控制记录，可用于实验追溯和研究性监督评估；它不得作为未知图像推理的隐藏输入。训练记录中的 Dice=0.880 来自小规模清洁留出集，不能外推为统一精度承诺。
