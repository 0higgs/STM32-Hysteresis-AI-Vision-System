# STM32F407 可编程磁滞回线模拟器项目交接文档

版本：历史交接记录（HYST-V1；V1.0 发布前保留）
交接日期：2026-08-13  
工程目录：仓库根目录下的 `firmware/`（开发机绝对路径已移除）

## 1. 交接结论

本阶段已经形成一套可直接用于磁滞回线显示与批量图像采集的完整系统：STM32F407 通过双通道 DAC、DMA 与 TIM7 持续输出磁滞回线；JDY-34 负责蓝牙串口通信；Windows 上位机支持参数控制、实时理论预览、预设切换、CSV/XLSX 参数表顺序执行；工程同时提供 500 组采集参数，其中 100 组正常样本、400 组八类瑕疵样本。

该阶段固件曾通过 Keil ARMCC 5 构建（0 Error、0 Warning）；V1.0 的发布镜像位于 `release/firmware/hysteresis_v1.hex`。历史 HEX 的 SHA-256 为 `1686325ACB76FC541A22F19F5099A275C0D52EBEE3F753293645B0571C577913`。

## 2. 系统组成与数据流

系统由三部分组成：

1. STM32 固件：生成回线点阵，通过双 DAC 循环输出，并解析蓝牙命令。
2. JDY-34 蓝牙串口：在 PC 与 STM32 USART2 之间透明传输文本命令。
3. PC 上位机：提供参数编辑、理论预览、设备状态、预设和批量参数表控制。

数据链路为：上位机参数 → Windows 蓝牙 SPP 虚拟串口 → JDY-34 → USART2 → 参数校验/波形生成 → 512 点弧长重采样 → 双 DAC 循环 DMA → 示波器 X-Y 模式。

## 3. 硬件接线

### 3.1 示波器与 DAC

| 信号 | STM32F407 引脚/外设 | 接入位置 |
|---|---|---|
| X 轴 | PA5 / DAC_OUT2 / DAC Channel 2 | 示波器 X（CH1）输入 |
| Y 轴 | PA4 / DAC_OUT1 / DAC Channel 1 | 示波器 Y（CH2）输入 |
| 信号地 | GND | 示波器两通道公共地 |

示波器应使用 X-Y 模式，两通道使用 DC 耦合。DAC 中点为 2048；默认幅度 1500 LSB，在 VDDA=3.3 V 时约为 0.44～2.86 V。可用示波器 POSITION 将约 1.65 V 的中点移动到屏幕中心。

### 3.2 JDY-34

| JDY-34 | STM32F407 | 说明 |
|---|---|---|
| TXD | PA3 / USART2_RX | 模块发送、MCU 接收 |
| RXD | PA2 / USART2_TX | 模块接收、MCU 发送 |
| VCC | 5 V | 当前 V7 所用 3.6～6 V 底板 |
| GND | GND | 必须共地 |
| EN | 3.3 V | 使能 |
| STATE | 悬空 | 本项目未使用 |

通信参数固定为 9600 baud、8 data bits、1 stop bit、无校验、无硬件流控（9600 8N1）。

## 4. 固件功能

### 4.1 磁滞回线模型

模型使用上下行双分支双曲正切曲线。`Hmax` 决定横向磁场范围，`Hc` 决定矫顽力及回线宽度，`Br` 与 `Bs` 分别控制剩磁和饱和磁感应强度。转折区加入平滑混合，避免分支切换产生尖锐跳变。

回线完成后，在 X-Y 平面按累计弧长重新均匀采样为 512 点。相比等相位采样，陡峭分支能够获得更多 DAC 点，可显著减少模拟示波器上“曲线变陡后变成散点”的现象。

### 4.2 输出链路

- TIM7 TRGO 同步触发两路 DAC。
- DAC Channel 2 / DMA1 Stream6 Channel7 输出 X；DAC Channel 1 / DMA1 Stream5 Channel7 输出 Y。
- 两路 DMA 均以循环模式持续输出 512 点。
- 参数更新时先生成到备用缓冲区，再复制到活动缓冲区；TIM7 与 DMA 不停机，避免应用参数后画面消失。
- 刷新率变化通过在线修改 TIM7 ARR 实现。

默认采样率为 100 kS/s，512 点对应回线刷新率 195.3125 Hz。

### 4.3 参数与范围

| 参数 | 含义 | 上位机范围 | 单位/说明 |
|---|---|---:|---|
| HMAX | 最大磁场 | 20～500 | A/m，且 HMAX>HC |
| HC | 矫顽力 | 1～100 | A/m |
| BR | 剩磁 | 0.05～1.5 | T，且 BR<BS |
| BS | 饱和磁感应强度 | 0.1～2.0 | T |
| LOOP_HZ | 回线刷新率 | 20～400 | Hz |
| X_GAIN / Y_GAIN | 横纵增益 | 0.1～2.0 | 倍 |
| X_OFFSET / Y_OFFSET | 横纵偏置 | -0.8～0.8 | 满量程比例 |
| XY_COUPLING | 轴间耦合 | -0.5～0.5 | 比例 |
| ASYMMETRY | 上下支路不对称 | -0.3～0.3 | 比例 |
| AMPLITUDE | DAC 幅度 | 200～1900 | LSB |

默认值为 HMAX=100 A/m、HC=25 A/m、BR=0.65 T、BS=1.20 T、LOOP_HZ=195.3125 Hz、X/Y 增益=1、X/Y 偏置=0、轴间耦合=0、不对称=0、DAC 幅度=1500 LSB。

### 4.4 预设

- SOFT：软磁风格，HC=10 A/m、BR=0.54 T，其余恢复默认。
- HARD：硬磁风格，HMAX=300 A/m、HC=60 A/m、BR=0.96 T，其余恢复默认。
- UNSAT：未充分饱和风格，HMAX=55 A/m、HC=25 A/m、BR=0.72 T，其余恢复默认。

## 5. 蓝牙文本协议

每条命令以 CR、LF 或 CRLF 结束。主要命令如下：

| 命令 | 作用 | 典型响应 |
|---|---|---|
| `PING` | 通信握手 | `PONG` |
| `GET STATUS` | 读取当前参数 | `STATUS ...` |
| `SET HMAX 100` | 修改单个待应用参数 | `OK` |
| `APPLY` | 应用整组参数 | `OK APPLY`，随后 `STATUS ...` |
| `PRESET SOFT` | 应用预设 | `OK PRESET`，随后 `STATUS ...` |

所有可设置键为：`HMAX`、`HC`、`BR`、`BS`、`LOOP_HZ`、`X_GAIN`、`Y_GAIN`、`X_OFFSET`、`Y_OFFSET`、`XY_COUPLING`、`ASYMMETRY`、`AMPLITUDE`。

错误响应包括：`ERR COMMAND`、`ERR PARAM`、`ERR RANGE`、`ERR PRESET`、`ERR LINE` 和 `ERR OUTPUT`。只有收到 `PONG` 才应视为 STM32 设备连接成功；仅成功打开 COM 口不代表通信链路已经正常。

## 6. Windows 上位机

入口文件为 `host_ui/main.py`。依赖为 Python、pyserial 和 openpyxl；安装与启动命令：

```powershell
python -m pip install -r host_ui\requirements.txt
python host_ui\main.py
```

最终版功能包括：

- 自动枚举 COM 口，连接、断开、刷新、PING 和读取状态。
- 仅在收到 `PONG` 后显示设备已连接。
- 串口读写放在后台线程，命令队列按 60 ms 间隔发送，避免 9600 baud 下阻塞 Tk 主线程和出现“未响应”。
- 12 项参数滑块与数值框，中文名称及单位完整显示。
- 参数变化 120 ms 防抖后自动下发；也可关闭自动应用并点击“立即应用”。
- 理论回线实时预览，采用与固件一致的模型和弧长重采样。
- SOFT、HARD、UNSAT 一键预设、恢复默认值。
- 预设按钮不再紧接着发送旧状态查询，避免第一次点击被旧参数覆盖而表现为需要点两次。
- 设备日志实时显示发送、响应及错误信息。

Windows 经典蓝牙 SPP 通常会生成“传出”和“传入”两个端口。上位机必须选择传出端口。当前开发电脑曾确认 COM12 为 JDY-34 传出端口、COM13 为传入端口，但重新配对后端口号可能变化，应以 Windows“更多蓝牙设置 → COM 端口”页面为准。

## 7. 参数表模式

上位机支持 UTF-8 CSV 和 `.xlsx`。必填列为 `HMAX`、`HC`、`BR`、`BS`；其余设备参数列可省略，省略时用默认值。`SAMPLE_ID` 仅用于采集编号和界面显示，不会发给 STM32；其他元数据列也会保留但不发送。

### 7.1 手动模式

加载表格后，使用“上一条”和“下一条”逐行输出。界面实时显示行号、总行数、样本编号以及带单位的完整当前参数。每次切换均等待设备返回与本行一致的 `STATUS`，确认实际应用成功。

### 7.2 定时模式

设置每行保持时间（0.5～3600 s）后启动。计时从收到设备确认状态后开始，而不是从点击按钮时开始；到时自动应用下一行。停止按钮可随时终止自动推进。

### 7.3 模板

- `host_ui/parameter_table_template.csv`
- `host_ui/parameter_table_template.xlsx`

Excel 模板包含参数表与字段说明页，可直接复制行并修改。

## 8. 500 组图像采集数据

最终数据文件为 `host_ui/capture_parameters_500.csv`，由 `tools/generate_500_capture_parameters.py` 使用固定随机种子 407500 生成，便于复现。共 500 行且 SAMPLE_ID 唯一：

- 正常样本 100 组，占 20%。
- 瑕疵样本 400 组，占 80%。
- 八类瑕疵各 50 组：过曝、过暗、拍摄不完全、失焦/运动模糊、偏置出屏、缩放裁切、倾斜/不对称、小而暗回线。

数据表除设备参数外，还包含 `DATASET_SPLIT`、`QUALITY_CLASS`、`DEFECT_TYPE`、`CAPTURE_INSTRUCTION`、`EXPECTED_EFFECT`，便于采集人员按行设置相机/示波器并进行后续标注。

注意：过曝、过暗、拍摄不完全和失焦/运动模糊属于相机或拍摄条件，不能仅靠 STM32 参数模拟，必须执行每行 `CAPTURE_INSTRUCTION`。偏置出屏、缩放裁切、倾斜/不对称和小而暗回线则主要由设备参数直接形成。

## 10. 构建、烧录与启动

1. 用 Keil MDK 打开 `Projects/MDK-ARM/atk_f407.uvprojx`，目标选择 `atk_f407`。
2. 执行 Build，确认输出为 0 Error、0 Warning；若需发布，核验后更新 `release/firmware/hysteresis_v1.hex`。
3. 通过 ST-Link 烧录 HEX，复位开发板。
4. 按第 3 节连接示波器与 JDY-34，示波器切到 X-Y、DC 耦合。
5. Windows 配对 JDY-34，确认传出 COM 口。
6. 启动上位机，选传出端口；收到 PONG 后再调参或加载参数表。

## 11. 验收清单

- 上电后无需 PC 即可看到默认磁滞回线。
- X 为 PA5、Y 为 PA4，方向与上位机预览一致。
- PING 返回 PONG；读取状态返回完整 12 项参数。
- 调整任意参数后画面持续存在，不因 DMA 重启而黑屏。
- 陡峭回线保持连续，不出现明显大间隔散点。
- 三个预设单击一次即可生效。
- CSV/XLSX 均可加载；手动上一条/下一条与定时模式正常。
- 定时模式必须在收到 STATUS 后才开始当前行计时。
- 500 组 CSV 行数、正常/瑕疵比例和八类瑕疵数量正确。
- Keil 最终构建为 0 Error、0 Warning。

## 12. 常见故障与处理

### 12.1 COM 口打不开或信号灯超时

确认未被其他串口软件占用；关闭旧上位机实例。检查选择的是 JDY-34 的传出端口而非传入端口。必要时删除配对并重新建立传出 SPP 端口。

### 12.2 COM 已打开但蓝牙连不上

以 PONG 为判断依据。检查 JDY-34 TXD→PA3、RXD←PA2、共地、9600 8N1；若无 PONG，先不要批量发送 SET 命令。

### 12.3 改参数后示波器无图像

先点“恢复默认”，确认示波器仍为 X-Y 和 DC 耦合；检查增益、偏置和 DAC 幅度是否令曲线整体出屏。确认烧录的是当前 `Output/atk_f407.hex`，而不是 vendor 目录中的旧 HEX。

### 12.4 曲线陡峭时出现散点

确认使用当前含弧长重采样的固件；适当降低刷新率可提高模拟示波器亮度。还应检查示波器带宽、余辉/亮度和探头接地。

### 12.5 上位机未响应或 Write timeout

确认只有一个程序占用串口。最终版已使用后台读写与 60 ms 发送节拍；若仍超时，先断开、重新配对并重新选择传出端口，避免连续快速点击。

## 13. 当前阶段边界与后续建议

本阶段交付的是“磁滞回线可编程输出 + 蓝牙控制 + 批量采集参数调度”。系统负责输出与采集条件编排，不负责自动控制相机快门、自动保存照片、图像与 SAMPLE_ID 自动绑定，也不包含图像质量识别/分类模型。若进入下一阶段，建议优先增加相机触发与文件自动命名，使设备确认的 SAMPLE_ID、参数、时间戳和图片形成一一对应的采集记录。

在修改固件、协议或表格字段前，建议先保留当前 HEX、构建日志和 500 组 CSV；新增协议字段应同步更新 `HystParams`、协议解析、状态回传、上位机参数定义、表格加载校验和本文档。
